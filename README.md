# Gym Tracker

Einfache Website (eine Datei: `index.html`), um Trainings an den Geräten im Gym zu protokollieren.

- Übersicht aller Geräte mit dem zuletzt bewegten Gewicht
- Pro Gerät: Datum, Sätze mit Kilo und Wiederholungen, optionale Notiz
- Letztes Gewicht wird beim Öffnen eines Geräts groß angezeigt, das Formular ist mit den Werten vom letzten Mal vorbefüllt
- Vergleich letztes vs. vorletztes Training, Gewichtsverlauf und kompletter Verlauf
- Als claude.ai-Artifact werden die Daten privat im eigenen Konto gespeichert (sonst lokal im Browser); über „Daten sichern/laden“ als JSON-Datei exportieren und importieren

Benutzung: `index.html` im Browser öffnen oder z. B. über GitHub Pages hosten.
